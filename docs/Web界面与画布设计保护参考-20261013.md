# Web 界面与画布设计保护参考

日期：2026-10-13；基线 `535b602` / v1.0.13。只用于现有 Web 版维护，不规划桌面版。

## 1. 设计保护目标

保留用户认可的无限画布、卡片、连线、工具栏、侧栏、主题和操作习惯。精简业务不能顺带改变颜色、间距、动画、弹窗层级和快捷键。开发前阅读根 `UI-PROTECTION.md`，新布局必须有独立的变更需求及回归证据。

来源区分：画布主体源自 basketikun/infinite-canvas；外层工作台包含另一路旧静态网页与本地适配。两者不能视为同一套完整可重新构建的 UI 源码。

## 2. 页面布局与职责

| 区域 | 当前行为 | 源码定位 |
| --- | --- | --- |
| 顶部 | logo、工作簿控制、产品胶囊；根据空间扩展显示，当前产品高亮 | `src/server/index.mjs`、`src/shared/data-contract/index.js` |
| 产品与画布 | 胶囊对应独立画布，新建/导入随当前工作表，命名联动，缓存切换 | `public/assets/local-canvas/canvas.js`、`workbook-canvas-products.js`、画布项目页 |
| 无 Excel 空白页 | 轮播与操作内容左右分区，支持深浅主题 | `src/server/index.mjs` 的空白页适配、`public/assets/local-canvas/canvas.css` |
| 无限工作区 | 自由节点、连线、选中、拖动、缩放、上下文菜单 | `src/canvas/pages/canvas/project.tsx`、`components/canvas/` |
| 浮动工具栏 | 添加节点、生成设置、图片工具、选择操作 | `canvas-toolbar.tsx`、`canvas-selection-toolbar.tsx`、`canvas-node-hover-toolbar.tsx` |
| 侧栏 | 资源/历史浏览、排序、重试、选择、下载、回收站 | `canvas-side-panel.tsx` 及外壳侧栏适配 |
| 设置 | 现有统一弹窗，包含本地存储、软件更新、渠道等；WebDAV 当前隐藏 | `components/layout/app-config-modal.tsx` 和各 config 组件 |

保护不意味着固化每个实现细节：可以替换旧外壳，但要以相同页面与操作录屏/截图对照，而不是换一套默认 UI。

## 3. 颜色、字体和形状

`src/canvas/lib/canvas-theme.ts` 是画布配色的直接参考：

| 元素 | 浅色 | 深色 |
| --- | --- | --- |
| 画布背景 | `#f4f2ed` | `#181715` |
| 节点面板 | `#fbfaf7` | `#1f1d1a` |
| 节点填充 | `#e7e5df` | `#292524` |
| 边框 | `#d6d3ca` | `#44403c` |
| 主文字 | `#292524` | `#f5f5f4` |

工具栏面板使用接近对应节点面板的半透明颜色。Ant Design 的独立 token 在 `lib/app-theme.ts`；Tailwind/公共 UI 变量在 `styles/globals.css`，基础圆角变量为 `0.625rem`。这不是所有节点统一圆角值，局部 class 仍需保留。

字体入口 `main.tsx` 使用 SF Pro Display、SF Pro Text、PingFang SC、Microsoft YaHei、Helvetica Neue 等回退。中文宽度与字重会影响胶囊、按钮和卡片换行，不能只对比英文截图。字体文件是否可分发还要单独核实授权。

外层空白页还有独立深色背景变量，例如 `#171717`、预览区域 `#262626`，不应机械替换成画布背景。保持系统主题、手动主题、logo、iframe 和 portal 弹窗同步。

## 4. 卡片、连线与交互约定

- 节点内容与外壳分离：`canvas-node.tsx`、`nodes/builtin-nodes.tsx`、`canvas-node-prompt-panel.tsx`、配置节点面板共同决定显示，不只改一个节点组件。
- 连线属于独立几何与渲染层：`canvas-connections.tsx`、`canvas-node-geometry.ts`、`canvas-node-size.ts`。拖动必须保持连接锚点、线条与节点同步。
- 新建、自动提示词、生成结果都应经过统一避让。整理重叠卡片入口保留在画布名称菜单，不恢复已撤销的重复入口。
- `infinite-canvas.tsx` 提供指针平移、空格/中键等交互与以鼠标位置为锚点的缩放，当前缩放范围 0.05–5。RAF 视口更新、pointer capture、输入控件和 no-zoom 区域的隔离都属于交互保护点。
- 项目页协调框选、多选、拖动、删除、复制及撤销重做。编辑文本时不能触发画布删除或快捷键。
- 设置弹层、下拉菜单和开关必须在画布上可点击，不得穿透；焦点与 Escape 行为需要浏览器验证。相关实现包括 Radix、Ant Design、公共 UI 和 canvas popover/dialog。
- 侧栏列表、图片详情、禁用按钮和开关需要同时验证深浅主题，不能仅对背景截图。

## 5. 关键流程保护清单

1. 无工作簿进入：显示空白引导 → 导入 Excel 或新建产品 → 顶部出现胶囊 → 切换后内容与名称一致。
2. Excel 提示词：识别主题/角度 → 参数卡连接 → 按主题应用对应变量 → 最终提示词 → 配置 → 生成；尺寸展示不能错误只填核心卖点。
3. 生成中切换：产品 A 发起任务 → 打开产品 B 操作 → A 后台结果保留 → 返回 A；不能白屏或把结果写入 B。
4. 文件管理：历史排序 → 选择 → 下载；无选择模式下载全部成功文件，选择模式只下载选中项；文件顺序与显示规则一致。
5. 数据恢复：误删参数卡 → 恢复已填变量；产品/历史进入回收站 → 恢复；ZIP 内容导入当前画布，不意外创建产品。
6. 更新：提示用户保存 → 关闭工作台页面 → 验签与切换 → 失败回滚；不要求关闭无关应用，不做保持页面打开的自动安装。

## 6. 以后如何做视觉与性能对照

首次实际精简前用测试数据固定浏览器尺寸、缩放、字体、主题与画布视口，记录空白页、密集连线画布、配置弹层、历史侧栏、图片详情、设置和产品切换。现有 `output/playwright/` 内有此前 v1.0.13 截图，可作历史参考；本次审计没有新截图验收，不能把旧图标成当前测试结果。

将界面截图与本文件的源码地图配对保存；截图不得带 API Key 或私人提示词。交互类问题用操作记录和运行测试补充，静态截图无法证明点击、保存和后台任务正常。

性能优化时保持相同节点/连线测试集，对比拖动帧耗时、切换耗时、长任务、内存与保存次数。只有测量证明改善且流程/视觉不退化，才算完成优化；不以“换框架”“删了多少行”作为验收标准。
