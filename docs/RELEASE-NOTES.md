## 1.0.7 — 2026-10-12

- 新建/编辑内置渠道、获取模型列表、配置文件导入和 Agent 连接先写入并读回 Keychain；浏览器持久化仅保存本机引用，失败保留原配置。

- 安全代理补齐 Gemini 视频文件下载，拒绝跨渠道下载和不匹配的凭据引用。
- 自定义请求脚本与安全凭据组合暂不支持；保存明确报错，已有配置保留。未进行真实付费 AI 请求或未配置 WebDAV/Agent 的远端验收。
- 更新渠道统一为 Champion-Guan/guan-ai-workbench；继续采用本机 arm64 构建、Ed25519 签名、每版本确认和关闭工作台页面后的安全安装。

## 1.0.6 — 2026-10-12

- 安装更新只需保存并关闭所有工作台页面，浏览器、其他网站、微信、Spotify及Clash Party无需退出。
- 逐个浏览器进程检查工作台标签页，支持同一浏览器的多个独立实例；查询失败或不支持的浏览器状态仍阻止安装。
- 保留每版本保存和任务结束确认、原生未决任务保护、后端冻结、签名验证及失败回滚。
- Chrome运行时的备份明确标记为稳定字节副本，不作为完整冷备份，也不自动恢复或覆盖浏览器数据；源文件变化则停止更新。
- 使用本机arm64构建及既有Ed25519可信密钥签名，GitHub Actions继续停用；不修改v1.0.5资产，不变更工作台Origin或私人配置。

## 1.0.5 — 2026-10-11

- 后续仅支持 macOS Apple Silicon（arm64），保留历史 Intel 资产不覆盖。
- 增加独立用户态 launchd 更新器、签名版本目录、首次维护引导、隔离启动、健康检查和启动失败安全回滚。
- 第一版采用每版本明确确认：先保存画布并确认生成、Agent、WebDAV结束，再退出所有浏览器；30分钟确认失效，未决任务、坏记录、保存失败和未知进程仍禁止安装，确认不能清除这些证据。
- 设置页复用现有软件更新界面，支持确认准备安装及稍后安装；打开开关或下载完成不会直接授权安装，自动安装默认关闭。
- 独立manager自身升级保留原supervisor及确切应用进程；升级失败恢复旧manager，supervisor自身更换须另行维护。
- 首次接管在最新完整私人目录/原Chrome离线备份和新维护确认后进行；不变更127.0.0.1:5174、不迁移或清空浏览器数据，不覆盖私人代理、Keychain helper或已生成文件。
- 实际隔离签名包与随机用户launchd演练覆盖首次安装、升级、启动失败回滚和manager升级；正式生产接管及两实体Mac仍须分别验收，不把测试夹具当作生产库存。
- 此版本仍不等于Apple Developer签名/notarization，旧v1.0.4不支持startupProtocol=1，不能直接当作自动回滚基线；请按安全引导说明接入。

## 1.0.4 — 2026-10-11

- 首个 GitHub 私有仓库签名 Stable，分别提供 Apple Silicon（arm64）和 Intel（x64）包，内置对应架构 Node.js v24.16.0。
- 采用所有者手动确认发布、固定源码提交、Ed25519签名清单与SHA-256；普通代码Push不会发布软件，个人迁移包不作为Stable。
- 软件更新页支持启动/每6小时/手动检查、Stable及SemVer过滤和可信后台下载；私有仓库需要每台Mac独立只读授权。
- 私人运行目录与代码隔离，保留原浏览器Origin及IndexedDB/localStorage，不包含个人API Key、代理配置、画布、历史或生成文件。
- 完善持久化失败保护和任务活动观察，未知任务状态拒绝安装。
- 重要：独立更新器、launchd自动安装/回滚与双实体Mac升级验收尚未完成；本版自动安装关闭。旧版本需先备份并人工引导，不能直接覆盖个人迁移目录或浏览器数据。
- 本版的Ed25519发布签名不等于Apple Developer代码签名或notarization；首次运行的Gatekeeper及Keychain兼容仍需受控验证，不建议直接批量分发客户。

## 1.0.3 — 2026-10-07

- 关闭启动终端时转发 SIGHUP，并统一清理运行中及启动中的代理子进程。
- 服务退出清理支持 SIGINT、SIGTERM、SIGHUP 和未捕获异常。
- 独立看护进程在服务被 SIGKILL 或意外终止后停止其所属代理；代理不响应正常停止时升级为 SIGKILL。
- 仅停止本服务创建的代理，不按端口或进程名称终止其他程序。已有孤儿代理仍需手动清理一次。

- 服务的 fetch 与 ProxyAgent 统一使用发布包内的 Undici，避免 Node 26 内置 fetch 与 Undici 6 代理接口不兼容。

- 个人迁移包继续包含渠道配置和私人代理配置。升级时保留已有浏览器数据，无需再次导入渠道配置。
