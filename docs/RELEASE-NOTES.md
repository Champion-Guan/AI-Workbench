- 本版的Ed25519发布签名不等于Apple Developer代码签名或notarization；首次运行的Gatekeeper及Keychain兼容仍需受控验证，不建议直接批量分发客户。

## 1.0.3 — 2026-10-07

- 关闭启动终端时转发 SIGHUP，并统一清理运行中及启动中的代理子进程。
- 服务退出清理支持 SIGINT、SIGTERM、SIGHUP 和未捕获异常。
- 独立看护进程在服务被 SIGKILL 或意外终止后停止其所属代理；代理不响应正常停止时升级为 SIGKILL。
- 仅停止本服务创建的代理，不按端口或进程名称终止其他程序。已有孤儿代理仍需手动清理一次。
