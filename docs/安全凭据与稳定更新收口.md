## 本轮实现

- 内置 OpenAI、Gemini、WebDAV、Agent 的凭据保存先经本机后端写入 macOS Keychain 并读回验证，再向浏览器返回引用。
- 已有引用须匹配本机 Origin、引用 ID、渠道类型、真实 endpoint 和 WebDAV 用户名；编辑、保存和同机便携配置导入保持兼容。
- 普通配置导出不含密钥、本机引用、代理路径和自定义脚本；导出前读取真实渠道地址，新电脑独立授权。同机仅匹配原身份和地址才保留凭据。
- 保存和导入失败保留原配置；配置在异步操作期间被改变时拒绝导入覆盖。WebDAV 使用编辑草稿及显式保存。
- Gemini 视频下载通过绑定渠道的安全代理，不允许跨 origin 使用凭据。
- Mac B 验收步骤见 `Mac-B-更新验收.md`。
