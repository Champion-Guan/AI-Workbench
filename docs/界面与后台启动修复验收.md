# 界面、迁移下载与后台启动验收

## 已实现

- 顶部胶囊与 Logo 留出 24px；设置“软件更新”紧随“本地存储”，隐藏 WebDAV 页签而不删除私人数据。
- 移除更新仓库编辑、Token 提示和授权状态；后端默认锁定 `Champion-Guan/AI-Workbench`，旧偏好读取不覆盖原文件。
- 迁移下载展示进度及固定错误代码；直连失败尝试系统/工作台已有本机 HTTP 代理。包损坏、签名拒绝、版本不符不重试绕过。
- 用户态 launchd 后台启动，终端退出不停止服务；再次启动可恢复已经退出的本项目服务，不强杀占用端口的其他进程。
- 启动建立桌面 `AI-Workbench.app`，不会覆盖同名客户文件；已有签名接管使用独立 supervisor，不并行启动第二个服务。入口依赖原安装目录，需保留该目录。
- 后续包名为 `AI-Workbench-v版本-macos-arm64.zip`，新版验证器继续识别历史包名。已发布旧客户端需兼容接入后才可使用新包名自动更新。

独立浏览器和临时服务实际打开设置：页签顺序符合要求，软件更新红框内容消失；公开更新信息正常显示。既有归档外部请求仍有控制台错误，不宣称整个项目无控制台错误。
