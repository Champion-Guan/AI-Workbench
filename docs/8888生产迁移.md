# 8888 生产端口迁移

## 一键入口

保存画布并结束生成，关闭工作台页面后，双击项目内
`scripts/迁移5174到8888.command`。其他网站和应用无需退出。
脚本没有控制台粘贴、逐步回车或手动选择安装包的步骤。

适用于 macOS Apple Silicon、已经接入独立 launchd 更新器的 5174 工作台，
并且原来保存画布的 Chrome 配置已加载本项目 1.0.1 或更新版受管理扩展。
Chrome 已退出时脚本会打开现有 Chrome，不创建新的用户数据目录；
若 Chrome 恢复了工作台标签页，则仍阻止迁移。
扩展不会读取其他网站、不更换 Chrome 数据目录，不通过本机桥传输画布或密钥；
迁移数据只在两个本机 Origin 与私人的临时备份服务间传输。
旧 1.0.0 扩展、未装扩展、其他浏览器或未接管个人包不具备自动迁移能力，
脚本会停止，不会把空配置当作迁移成功。已有的 v1.0.8 发布资产没有被改写，
本工具及新版扩展需要使用当前源码目录；不能只复制一个 `.command` 文件。

执行时自动从公开仓库 `Champion-Guan/AI-Workbench` 获取最新 Stable arm64 包，
先验证内置可信 Ed25519 签名、SHA-256、文件库存和启动协议，再开始备份迁移。
网络失败或不兼容时停止，保留原服务。维护人员仍可传入一个已下载的签名资产目录。
首次页面检查与下载后页面检查均通过，才打开扩展自己的临时迁移页；
复制并逐项验证成功，关闭临时页并再次检查页面后，才切换确切自有服务。
安装事务开始后不要强制结束终端或关机，让安装器完成健康检查或回滚。

目标 8888 已运行时直接跳过重复迁移，不读取旧 Origin、不写数据；
这只证明目标服务已运行，不代替浏览器数据校验。目标非空、端口未知占用、
校验超时、下载验签失败均停止，不清库、不覆盖、不按端口杀进程。
自动备份位于 `~/Library/Application Support/GuanAIWorkbench/backups/port8888-*`。

本次只构建、签名和安装到所有者 Mac，不自动发布 GitHub Release。

`scripts/port-migration-bridge.mjs` 提供临时本机迁移页：旧 Origin 只读导出，
备份写入私人备份目录；新 Origin 只执行 copy-once 和逐记录、Blob 字节验证。
迁移失败禁止覆盖目标。沉浸式翻译的 `__imt_handshake_page_id` 保留为目标页面的
扩展临时状态，不复制旧页面标识；其他会话、配置和数据库非空仍拒绝迁移。

`scripts/migrate-production-port.mjs prepare` 只验签、暂存正式格式的本机包，
准备独立不可变运行时。`install` 只在用户保存确认且 5174/8888 工作台页面均关闭时执行。
安装通过既有签名、OwnedUpdateService、事务切换与健康验证：先停确切自有应用，
再停止旧 supervisor，替换两个精确匹配的 launchd 配置，启动新版 supervisor，
安装并激活应用，最后启动新版独立管理器。

旧版本、旧 Origin 存储、Keychain、私人配置及备份保留。
同步故障恢复旧启动配置、安装指针与管理元数据，不恢复覆盖浏览器数据库或私人数据。
维护期间意外关机应保留备份和事务记录，由人工核实后恢复，不按端口强杀或重新初始化。

默认入口为 `http://localhost:8888`，后端重定向到 `http://127.0.0.1:8888`。
更新时只要求关闭 8888 工作台页面；其他网站和应用可继续使用。
自动安装保持当前偏好，不因为本次维护擅自开启。

实际执行结果以私人目录的 `MIGRATION.json`、`PORT-SWITCH.json` 及服务健康读回为准，
代码实现和样包测试不能当作实际生产迁移证明。
