# 工作台源码迁入 Fork 仓库

日期：2026-10-13。

## 仓库安排

- 当前源码仓库： https://github.com/Champion-Guan/infinite-canvas
- 上游： https://github.com/basketikun/infinite-canvas
- 旧工作台仓库和已发布 Stable： https://github.com/Champion-Guan/AI-Workbench

将已关联上游历史的工作台分支快进到 fork 的 main，保留原作者 448 次提交和工作台历史，不 force-push、不删除旧仓库。本地项目目录保持原路径，避免影响正在运行的 launchd 源码服务；“搬仓库”不需要搬动私人配置或本机工作目录。

本地 origin 改为 fork；旧 origin 保留为 legacy-origin；upstream 仍指向原作者。fork 的 Actions 停用，延续所有者不使用 Actions 的要求，不触发迁入后的构建/发布任务。

## 运行和更新边界

当前默认端口与 Origin 仍是 8888、127.0.0.1。迁入仅修改仓库说明与 Git 关系，不改变前端、后端业务行为或浏览器数据。

软件更新继续指向旧仓库：既有 Stable 清单包含签名仓库身份，把资产复制到新仓库不能自动变成合法的新渠道。本次不移动标签、不重签历史包、不清理旧 Release。未来若决定新版本在 fork 发布，需专门修改固定仓库、可信身份兼容、发布所有者校验、相关测试并验证旧客户端升级路径。

GitHub fork 标签中已有上游版本名；工作台版本可能与其冲突。以后正式发布须先核实标签占用，不能覆盖上游标签。

## 验证

迁入前检查 Git 工作区并保留两份审计文档；当前源码及合并后的历史执行敏感信息扫描，暂存内容执行扫描和 whitespace 检查。推送后读取远端 main，验证其 SHA 等于本地提交，上游基线与旧工作台基线均为祖先，并核实 GitHub fork 来源和 Actions 停用。

回退时旧仓库 main 和 Release 保持原样。恢复 origin 地址或使用 legacy-origin 即可读取旧仓库，不以重置浏览器存储作为回退方式。
