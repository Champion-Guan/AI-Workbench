## 已确认的实施方向

用户明确批准“受管理工作台浏览器窗口”：保留原 127.0.0.1:5174 和已有数据，普通访问继续兼容；普通窗口、旧任务或未知参与者不能被零报告消除。**方向已批准，不等于代码已经实现。**

受管理窗口不能另建空浏览器 profile 后声称原数据可用，也不能只打开一个新窗口便把所有其它窗口视为空闲。需要可信的浏览器层全窗口/iframe 库存、旧页检测和持续拓扑 revision；原生桥接必须限定身份与操作，页面自注册不授予安装权。若实现需要浏览器扩展安装/配对或其它系统变更，应先验证具体方案和回退路径，不静默改 Chrome 配置。

收口顺序：完整受管理窗口及业务准入/持久化、持久远端任务证据、独立 supervisor 与管理器恢复/升级、全部失败演练；随后单独批准协议兼容的新正式 Release，在新维护确认及完整备份之后做首次生产接管。未满足前不进入阶段 6、不开放自动安装。
