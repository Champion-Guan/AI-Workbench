# PixPix 工具页静态归档

此项目只包含 17 个指定的工具页面及其本地 HTML、CSS、JavaScript、字体、图片和媒体资源。它不含代理、登录、积分、云端模型接口或其他 PixPix 路由。

启动命令：npm run dev

默认入口是 http://127.0.0.1:5174，直接打开 A+/详情页且地址栏保持简洁的根路径。原 `/zh-CN/tools/detail-page` 地址继续兼容；除该地址、根地址和内部 `/_pixpix-assets/` 静态资源路径外，所有路由均返回 404。

## 当前第一期入口

当前开发版本只开放一项图片能力：

- `/zh-CN/tools/detail-page`：A+/详情页

工作台容器当前铺满浏览器视口，不保留外层灰色留白、圆角或边框。
品牌与工具入口使用顶部横向栏，横线下方为主工作区。
无论窗口宽度如何变化，顶部均固定显示“A+/详情页”，不会降级成下方下拉菜单。

其余 16 个页面已从导航和服务路由中下线，访问时返回 404；完整静态文件仍由 `archive/full-17-pages` 分支保留，供后续商品套图、视频、穿戴或其他功能阶段恢复。

## 版本与回退规则

- `main` 是当前正在开发的版本。
- `archive/full-17-pages` 是完整 17 个静态工具页的保留分支，不作为日常开发目标。
- 每项改动开始前，先在当前可运行提交上创建 `restore/` 标签；改动完成并经过本地验证后再创建一次提交和标签。
- 暂时不需要的工具先从当前产品的导航和路由中下线，源文件仍保存在归档分支中。只有需求确认不会再使用时，才从 `main` 清理。
- 如需回退，优先切回对应 `restore/` 标签或 `archive/full-17-pages` 分支，不使用不可恢复的文件删除操作。
