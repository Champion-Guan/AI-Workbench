# Guan A+ 详情页工作台

这是一个完全本地的单页面静态工作台，只保留 A+/详情页功能。

启动：

```bash
npm run dev
```

默认地址：[http://127.0.0.1:5174](http://127.0.0.1:5174)

页面地址：[http://127.0.0.1:5174/zh-CN/tools/detail-page](http://127.0.0.1:5174/zh-CN/tools/detail-page)

项目不提供登录、云端接口或其他工具路由。根路径和详情页路径指向同一页面，其他路径返回 404。历史版本和完整备份不放在当前项目运行路径中。
